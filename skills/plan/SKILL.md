# Plan Skill

Use this skill when tackling tasks with 3 or more distinct steps or architectural choices.

## Guidelines
1. Enumerate all constraints, edge cases, and failure modes first.
2. Structure the plan into sequential, independently verifiable milestones.
3. Record progress using the `todo` tool (keep exactly one item `in_progress`).
4. Avoid run-ahead: build only the step requested and verify before moving forward.
